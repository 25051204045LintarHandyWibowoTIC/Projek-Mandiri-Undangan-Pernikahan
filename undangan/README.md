# Undangan Pernikahan Digital (HTML + CSS + Bootstrap + JS)

## Cara menjalankan
Buka `index.html` di browser (atau Live Server di VS Code).

## Cara mengubah data
Buka `js/script.js`, ubah objek `DATA` paling atas (nama, tanggal, lokasi, rekening, ucapan awal).
Link lokasi: ubah `q=` pada iframe `#peta` dan tombol `#btnPeta` di `index.html`.

## Memasang media (taruh di folder `assets/`)
foto-hero.jpg, foto-pria.jpg, foto-wanita.jpg, galeri-1..6.jpg, poster.jpg, video.mp4, musik.mp3, qris.png
Selama file belum ada, kotak placeholder tampil otomatis.

## Nama tamu
`https://domainmu.vercel.app/?to=Budi%20dan%20Ani`

## Deploy Vercel
Upload folder ke GitHub, import di vercel.com, Framework Preset: Other, Deploy.
